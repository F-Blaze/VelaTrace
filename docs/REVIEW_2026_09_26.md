# September 26 follow-up review

Reviewed the combined PR #1 revision `e107443`, including the maintainer's changes in `4894d8b` and merged PR #2. The initial complete local run passed 114 tests and 77 subtests, including native Freerouting/Java and KiCad CLI integrations; Ruff passed. Passing that suite did not cover the defects below.

## Corrections from the follow-up review

- DSN connectivity stripped any trailing `@digits`, including literal pad identifiers. It now derives the export aliases from ordered pad occurrences, counts unconnected pads, and refuses ambiguous aliases or changed net assignments.
- SES placement used a tolerance controlled by the file's own resolution, allowing changed positions and fractional rotations. Placement now binds to accepted DSN precision and checks the pinned router's exact integer rounding.
- KiCad echo comparison omitted protobuf zero-valued coordinates, allowing different geometry to pass. Critical geometry is explicitly compared, with narrowly supported server defaults.
- A failure reading the board after a committed removal could escape without marking the result uncertain. Verification errors now block retry and retain the recovery evidence; addition-only commits avoid the unnecessary removal read.
- Transformers 5 returns a mapping by default from `apply_chat_template`; taking its length reported two fields instead of input tokens. The counter explicitly requests token IDs and refuses unexpected return types. The tokenizer dependency now includes Jinja2, needed for rendering the chat template.

The Windows Specctra path handling, separate KiCad string escaping, KiCad 10 inline net names, strict placement metadata, and explicit close-without-cleanup warning remain intact.

Final local regressions: **131 tests and 98 subtests passed, zero skips**. This run used the installed KiCad 10.0.4 CLI, Freerouting 2.1.0, Java 21 and the pinned SDK/Qt dependencies. Ruff and whitespace checks passed. The permanent local Java/Freerouting installation also passed the production startup verification.
